# v1 UI prototype delivery

**10 standalone prototypes saved: six desktop, two iOS and two Android.** Visual/interaction proposals only; all values are fictional.

[Offline/browser gallery](/prototypes/v1/index.html) · [Interaction specification](../ui-prototype-v1.md) · [Prompts/revisions](https://github.com/cuihairu/rillane/blob/main/docs/design/ui/prompts.json)

Files live in `docs/public/prototypes/v1/`. Open index.html directly; manifest.json records dimensions, SHA-256 and revisions. Generated with built-in image_gen and copied into the repository, with prompts and four revision prompts preserved.

Images define layout/theme; logos/icons are not a frozen brand system. Implementation follows the interaction specification, actual capability receipts, single-count business totals, measured streaming results and mobile identity limits. iMac processes were confirmed, but no live window screenshot was obtained; references use official previews/App Store information.
